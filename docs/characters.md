## 二、共同约定

这几条是写台词、写任务描述、写提示词时都要守的硬约定（违反就会出现「现代人混进中世纪」的破功感）：

1. **称呼玩家一律「殿下」**，自称各有各的说法（塞巴斯蒂安「老臣」、其余「属下」或直说）。
2. **不出现现代词**：不要「面板」「页签」「界面」「点击」「解锁进度」「数据」「数值」。
   要说「账本」「名册」「文书」「图样」「陛下的旨意」「你把它打开」。
3. **不解释系统**：谁也不说「这个功能」，只说「这一行该修桥」「这里的税该收」。
4. **每个人只看自己那一摊**：薇拉不谈麦子，露娜不谈账本，阿尔文不谈人口。
   唯一越界的是雷纳德 —— 他代表国王，什么都问。
5. **好感度不能靠刷**：见 §六（口径还没定，先别写进代码）。

### 5.3 抠图口径（要重跑时照这个来）

绿幕图和成品都在，重跑一次只要两条约束：

- 键控：`key = G - max(R, B)`；绿底 = 255，主体 ≤ 0。`key < 140` 判为主体
  （140..215 那一段是背景上的暗边，必须丢掉，否则人物轮廓外面会多一圈绿影）。
- 去绿：过渡带的颜色按 `F = (C - (1-a)·B) / a` 反解（**未预乘**），再对还绿占优的像素
  把 G 压到不超过 `max(R,B)`。这套图里没有「天生是绿」的部位，所以可以无脑压
  （实测七个角色的眼睛都不算绿占优，压完不掉色）。
