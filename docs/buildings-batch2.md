### 占地换算（附表）

**先纠正一个口径**：这批图是 **2 倍像素密度**（128 px 宽在游戏里只该占 4 格）。
直接 `floor(px/16)` 会让每座都比现有建筑大一圈，所以要**除以 2、再扣掉最上面那一行**。

而且这件事**不该手算** —— 现有管线里有两层机制（`scripts/gen-art.ts`）：

| 机制 | 作用 |
|---|---|
| 显示档位 | 源图按整数倍缩放到"层高上限"以内：1 层上限 80px、2 层上限 128px；只取 ×1 / ÷2 两档 |
| `FORCE_HALF` / `FORCE_NATIVE` | 点名覆盖档位（"小建筑档" / "大建筑档"）——`伐木场`、`粘土坑` 在 HALF，`研究所`、`家政工坊` 在 NATIVE |
| `art.foot` | 占地**由 content 声明**，与贴图解耦：贴图可以比占地高，往上遮住身后的建筑 |

⚠️ 关键：**占地是拿"运行时贴图"推的**，不是拿源图推：
```
foot = ( floor(W_rt / 16),  max(1, floor(H_rt / 16) - 1) )      # W_rt/H_rt = 缩放后的显示尺寸
```
`check:footprint` 里的"贴图推导"就是这一行 —— 现有 32 座里只有 `town_center` 是手写覆盖，
其余全部等于这个推导。所以"÷2 + 扣顶行"和现有口径是同一件事。

**这批的档位安排**（用户 2026-10："都除以2；学校 / 贸易市场 / 诊所 / 医院 不要缩小"）：

- 绝大多数进 **`FORCE_HALF`**（显示 64 宽，与伐木场/粘土坑同档）
- **诊所 / 医院 / 贸易市场 / 学校** 进 **`FORCE_NATIVE`**（按原生 128 宽显示，和家政工坊/研究所同档）

### 3.2 工具：耐久 + 加成（本批唯一的机制改动）

现状：`economy.tools.perWorkstation = 0.1`（所有工具一个速率），加成写在商品 `toolBonus` 上。

改为**每种工具各写耐久**，消耗 = 每工人每天 `1 / 有效天数`：

```jsonc
// content/goods.json
{ "id": "stone_tools", "toolBonus": 0.25, "durabilityDays": 10 },   // 现有，补一个字段
{ "id": "iron_tools",  "toolBonus": 0.60, "durabilityDays": 15 },   // 新增（用户：铁制更耐用、加成更高）

// content/economy.json
"tools": { "order": ["stone_tools", "iron_tools"], "perWorkstation": 0.1 }  // perWorkstation 退化成兜底
```

**有效天数 = 耐久 × (1 + 工具寿命加成)**，寿命加成来自科技（加法叠加）：

| 科技 | 效果 | 石制有效天数 | 铁制有效天数 | 每人日耗（铁制）|
|---|---|---|---|---|
| —（基础）| — | 10 | 15 | 0.0667 |
| 淬火 `tempering` | 寿命 **+20%** | 12 | 18 | 0.0556 |
| 精炼 `refining` | 寿命 **+50%** | 15 | 22.5 | 0.0444 |

- 两条科技**加法叠加** → 都研究完 +70%（与现有"效率科技逐级加法叠加"同一套口径）
- 加成仍是"只放大产出、不放大投入"，与石制工具完全同轨
- 分配仍从 `economy.tools.order` **从高级往低级找**：有铁制工具就用铁制，不够才退回石制
- 兼容：没写 `durabilityDays` 的工具（老内容）按 `perWorkstation` 兜底，行为不变


## 6. 贸易市场与游商（本批唯一的新系统）

### 6.1 定位

贸易市场是**建筑 + 面板 tab**；游商（caravan）是**来访的商人**，不是地产出。
本版只做**第一个 tab「游商」**（用户第 9 条），第二个 tab（商路/常驻贸易）留空。

### 6.2 节奏（用户第 9 条）

| 阶段 | 同时到访的游商数 | 触发条件 |
|---|---|---|
| 第 3 章开始 | **1 个 / 周** | `quests.chapters["3"]` 有记录（= 第 3 章完成）|
| 第 4 章开始 | **2 个 / 周** | `quests.chapters["4"]` 有记录 |
| 第 5 章开始 | **3 个 / 周** | `quests.chapters["5"]` 有记录 |

- **停留 7 天**：第 `D` 天到达 → 第 `D+6` 天是最后一天 → 第 `D+7` 天 06:00 离开
- 每周一批（每 7 天）：第 1 批 = 第 3 章完成后的第一个黎明；之后每 7 天一批
- 同一批里的多个游商**各自独立报价**（不同商品），这样"同时两个"是真的两种选择

### 6.3 每个游商：收 4 卖 4

| 方向 | 数量 | 价格 | 限制 |
|---|---|---|---|
| **收购**（玩家卖给他）| 4 种商品 | `baseValue × 1.6`（高价，用户说"收购高价"）| 每种最多收 N 件（建议 20），付金币进国库 |
| **出售**（玩家从他买）| 4 种商品 | `baseValue × 1.3` | 每种库存 N 件（建议 20），花国库金币 |

- 商品池：本内容包 `goods` 里、**玩家已解锁**的（避免剧透后期商品），按 `seed = day × 1000 + 游商序号`
  的 RNG 抽 8 种（4 收 4 卖），**确定性**（golden 与 AI 沙盘都可复现）
- 一批里多个游商：1 号先抽，2/3 号从剩下的里抽（尽量不重复）
- 金币不够 / 库存不够 → 按钮置灰并写原因（与现有面板同一套口径）

## 附：这批建筑的一句话定位

- **冶炼场**：铁矿石 + 煤 → 铁锭。全游戏第一条"两种原料都来自地图矿脉"的配方。
- **铁制工具作坊**：把"工具"从一次性道具变成**产业升级阶梯**（石 +25%/10 天 → 铁 +60%/15 天）。
- **淬火 / 精炼**：让"工具更耐用"成为可研究的**复利科技**（省的是整条产业链的工具开销）。
- **武器 / 盔甲 / 弓箭作坊**：本版先服务**治安**（治安所吃武器），军队以后再说。
- **草药 → 药水 → 诊所 → 医院**：一条**四级纵深**的链，第一次让"服务"有前置原料。
- **学校**：第一次把"人力质量"变成可投资的建筑（熟练度成长 + 教育满意度）。
- **治安所 / 瞭望台**：治安的**两档供给**（耗武器但量大 / 不耗武器但量小）。
- **贸易市场 + 游商**：本版唯一的**新系统**，把"囤货 → 换钱"这条路打开（现在仓储满了只能丢）。
