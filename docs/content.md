## 二、产业链（37 座建筑）

格式：`建筑（满员工人）：投入 → 产出`。`baseRate = 1 批次/满员·天`；`🔥` = 额外消耗 `firewood`。
**32 座有配方；建筑工坊产建造力、研究所产科研力、城镇中心与仓库提供仓储 —— 这四座没有配方**
（分别见 `docs/construction.md`、`docs/technology.md`、`docs/town.md`）。

> 2026-10 新增两座（`docs/town.md`）：
> - **城镇中心**（0 工人，开局自带一座）：仓储 **1000**，无科技锁；
> - **仓库**（1 工人 / 上限 2，可升级）：仓储 **300** + 每级 **150**，无科技锁，木 8 石 6。
>
> 仓储是**全局总量**口径（所有商品数量之和），超了当晚按 `baseValue` 升序丢；
> 另外还能逐项设**软上限**防止单一物资占满空间。

### 链 7 · 家政服务（富 / 老板需求）

```

```
> 家政服务的收入由富/老板支付，经政府转为家政工人的工资 —— 让富人的钱回流到普通劳动者。

### 链 8 · 娱乐（中产 / 富 / 老板需求）

```
剧院(5)                  → 5 娱乐（无投入；不可储存，当日消耗）
```
> 不同阶层每天消耗的娱乐产能不同，**层级越高消耗越大**：中产 0.1、富 0.3、老板 0.6（人均·天）。
> 娱乐属奢侈品（低弹性），按 2.5× 加价，专门让中产/富/老板花钱。

> 非耐储商品每日按 `perishRate` 损耗：蔬菜 10%、肉类/鱼类 15%、家政服务 100%（不结转）。

> **建造力**是**每日产能（速率）**，由失业人口与建筑工坊的工人提供，施工时逐日消耗
> ——建筑的"建造力成本"就是工人的劳动（其工资由政府支付）。详见 `docs/construction.md`。

🔥 燃料统一消耗 `firewood`：砖窑 4、陶器坊 3、熏鱼坊 4、肉干坊 4。

## 三、建筑建造成本

建造成本 = **实物原料**（开工时才扣，下单只检查够不够）。实物材料取自当前 pack；全为包外商品时回退货币成本。
**工期**由 `buildWork`（建造力需求，人·天）÷ 每日产能决定，不再是固定天数。

| 等级 | 实物成本 | 货币回退 | 工时 `buildWork` |
|---|---|---|---|
| tier 1（一级产业） | 木材 4 | ¥100 | 采集 12 / 加工穷人级 12 |
| tier 2（二级加工） | 木材 6 + 石块 3 | ¥250 | 加工中产级 24 |
| tier 3（三级投资） | 木材 8 + 石块 6 + 粘土 4 | ¥500 | 加工富人级 36 / 大型 48 |

- 建筑工坊本身只用原料（木材 6 + 石块 4）——避免"没有建造力就造不出建筑工坊"的死锁；
  它是**建造力的唯一增量来源**（一人顶两个闲人），v1.0 开局即自带一座。
- 扩产（+1 等级）成本 = 上述实物成本 × 当前等级；无实物材料时 = `¥80 × 等级`；工时 = `24 × 当前等级`。
- 住房建造走 `build_housing`，成本为材料；工时 = 茅屋 12 / 木屋 24 / 砖房 36。
- 土地上限 `maxBuildingSlots` 当前为 **无限**。
- 建造与升级**共用一条先进先出队列**，串行施工。

## 四、阶层需求（消费）

| 阶层 | 需求（人均/天；括号为缺货/买不起时的替代品）|
|---|---|
| 穷人 poor | 粗面包 1.0、蔬菜 0.5 |
| 中产 middle | 白面包 0.5（→粗面包）、肉类 0.2（→鱼/熏鱼/肉干）、粗布衣 0.05（→常服）、陶器 0.03、娱乐 0.1 |
| 富人 rich | 糕点 0.3（→白面包）、瓷器 0.05、家政服务 0.3、娱乐 0.3、常服 0.1（→粗布衣）、华服 0.05（→常服）、皮衣 0.05（→常服）|
| 老板 boss | 糕点 0.3、瓷器 0.1、家政服务 0.5、娱乐 0.6、华服 0.1 |

- 食物类需求 → 决定**食物满足率**（买不起就挨饿）；食物需求还会兜底到基础食物（粗面包/蔬菜）避免高级食物缺货时饿死。
- 非食物需求 → 决定**舒适度**（缺货只降满意度，不饿死）。
- 消费为**逐居民**结算（各自用自己的存款购买），货币守恒。

## 八、动作清单（AI / 玩家）

| 动作 | 说明 |
|---|---|
| `set_wage { shopId, value }` | 设定该店基础工资 |
| `set_wage_cap { shopId, value }` | 设定该店每人实际工资上限（0=不限） |
| `set_workers { shopId, value }` | 设定目标用工数。上限 = **有效工位数**（`maxWorkers + capacity.slotsPerLevel × (等级−1)`），0 = 停产。UI 是拖动条 |
| `set_price { goodId, value }` | 设定商品售价；住房商品即售价 |
| `expand { shopId }` | 扩产（+1 等级） |
| `toggle { shopId, active }` | 开 / 关 |
| `demolish { shopId }` | **拆除**：直接销毁一座**已建成**的建筑。**退建造资源**（按 `buildCost` 退回），**不退建造力**；里面的工人变回失业；释放占用的地格。在建的走取消施工那条路。面板上要过二次确认窗 |
| `build { buildingId }` | 建店（进入施工队列） |
| `build_housing { goodId }` | 建造公房（提升人口上限，占土地名额） |
| `set_rent { value }` | 设定公房人均日租金 |
| `set_population_cap { value }` | 人口上限：迁入到这个数就停。**迁入不看岗位数**，规模全靠它兜住 |
| `set_tax { value }` | 设为单一扁平税率（覆盖整张税表） |
| `set_tax_bracket { index, upTo?, rate? }` | 编辑累进税某档的阈值 / 税率 |
| `end_turn` | 结算一天 |

预留（返回 `not_implemented`）：`sell_shop`、`retake_shop`、`subsidy`。

## 九、货币来源与销毁

- **凭空产生（唯一持续注入）**：每个新移民自带 12 存款（`makeResident`）。
- **初始**：政府 1000 + 每开居民 12。
- **死亡（饥饿）**：存款**充公归政府**（不销毁）。
- **迁出（满意度低）**：带走自己的存款（离开系统）。
- **货币建造**：仅当建筑无可用实物成本时才扣钱（销毁）；v0.3 走实物，故基本不烧钱。
- **其余全为转账**（工资 / 消费 / 租 / 买房），守恒。
- **政府余额无下限**：可持续为负，等价于**隐性透支 / 发钞**（居民存款即对政府的索取权）。

## 十、每日结算循环

每天 `advanceDay(state, [...end_turn])` 的**固定顺序**（`src/engine/tick.ts`）：

| 步 | 阶段 | 说明 |
|---|---|---|
| 1 | **用工** | 按目标用工把居民分到各建筑：口粮链优先 → 其余按需求比例 → 矿场/林场吸收剩余。停产建筑不占人。 |
| 2 | **生产** | 以「**昨天结束时的库存**」为基准。先统计所有建筑对每种原料的总需求，得出统一分配系数 `可用 / 总需求`；每座建筑取自身各原料系数的最小值作为实际批次 → **所有建筑按同一比例缺料，与建筑顺序无关**。产出 = `baseRate × (到岗/满员) × 熟练度系数 × level × 分配系数`。 |
| 3 | **发工资** | 政府按 gross 发薪（技能挂钩 `工资 × (0.5+技能/100)`、每人实际工资受工位 `wageCap` 封顶），按累进税代扣。 |
| 4 | **住房占用 + 收租** | 按阶层分配住房占用；公房租金 → 政府，私有住房租金 → 房东（房东的租金收入按累进税计征）。 |
| 5 | **购买消费品** | 逐居民按自身需求、用**自己的存款**购买；食物需求决定食物满足率（买不起就挨饿），非食物需求决定舒适度。 |
| 6 | **投资：买房（买房）** | 仅中产及以上，且买与本阶层等级对应的住房；成交后转为私有。之后**重算住房占用**，新业主当天生效。 |
| 7 | **结算满意度** | 食物 / 工资 / 价格 / 就业 / 舒适度 加权 + 阶层加成 + 住房调整（房主/房客加成、租金负担、住低档扣分）。 |
| 8 | **人口** | 饥饿死亡（存款充公）、满意度低迁出（带走存款）、按财富分层。 |
| 9 | **迁入** | 引擎算出「想来人数 `arrivals`」（满意度 + 昨日饥饿率决定）；`admit = min(arrivals, 住房余量, 人口上限−人口)`。**不看岗位数**，规模由 `set_population_cap` 兜住。 |
| 10 | **施工完成** | 建店施工队列推进。 |
| 11 | **损耗** | 非耐储商品按 `perishRate` 折损（服务 = 100%，当天归零）。 |
| 12 | **计算下回合「想来人数」** | 写入 `state.arrivals`。 |

> 一句话：**期初库存 → 按需公平生产 → 发工资 → 收租 → 消费 → 投资买房 → 结算满意度**。
> 生产永远以「同一天的期初库存（= 昨天期末）」为基准，且公平分配，不依赖建筑顺序。
