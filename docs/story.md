# 故事设定

> **一句话**：你是一个被分封到边陲的王子。国王派了特使过来，看他这块地到底能不能养人。
>
> 人物档案见 [characters.md](characters.md)。**标记约定同那一份**：没标记的是**你定的**，
> 带 **〔拟〕** 的是我补的、随时可推翻。

---

## 一、你是谁

**分封到边陲的王子。**

- 你有一块封地、一个头衔，和一群愿意跟你走的人。
- 你手上**只有这些**〔数字取自 v0.3 开局〕：**12 个人、6 座茅屋、一座城镇中心、2000 金**。
  不是「王国给了你一支军队」，是「王国给了你一个空壳，看你怎么填」。
- 你要做到的事：**把 12 个人的营地养成 1000 人的村镇**。这就是六个章节从
  「先吃饱」一路排到「千人之村」的原因。

为什么是你被分封到边陲 —— 设定里没说。三种做法都成立〔拟〕：

| 读法 | 味道 |
|---|---|
| **历练** | 国王真的想让你成器，边陲是考场 |
| **放逐** | 王庭里有人不想再看见你，边陲是体面的流放 |
| **试探** | 国王还没决定你是儿子还是麻烦，边陲是观察窗 |

三种读法**不冲突**：雷纳德的每一句话都可以同时是关心、是监视、是最后通牒 ——
这正好是他这个人最好用的地方。选哪一种只影响他台词的**底色**，不影响玩法。

---

## 二、这块地

- 名字：**索维特（Sovit）**。村子由你命名（新游戏里 ≤6 字）。
- 位置：王国的边缘。有林、有水、有矿脉；地够广，人太少。
- 边陲的意思很具体：**从王庭到这儿要走很久**。所以出了事没人来救，做成了也没人来抢。
- 尺度感：开局一座城镇中心，周围几顶茅草屋。到一千人时，这里得有自己的磨坊、砖窑、
  织坊、剧院和私宅 —— 一个能自己活下去的地方，而不是一个听命于人的营地。

| 人 | 站在哪一边 | 他在你耳边说什么 |
|---|---|---|
| 塞巴斯蒂安 | **家臣** | 「殿下，老臣建议……」—— 怎么把日子过下去 |
| 阿尔文 | **家臣** | 「殿下，这个科技可以解锁。」—— 能做出什么新东西 |
| 薇拉 | **家臣** | 「殿下，国库又要空了。」—— 钱还剩多少、花得值不值 |
| 露娜 | **家臣** | 「殿下，村里又添了新丁。」—— 人愿不愿意留下 |
| 雷纳德 | **国王那边** | 「殿下，这是国王陛下的旨意。」—— 你做到了没有 |
| 伊莎贝拉 | **她自己那边** | 「哼，我才不是来看你的。」—— 你为什么还没睡 |
| 瑟拉菲娜 | **谁也不跟** | 「哼，才不是特意为你预言呢。」—— 前面有什么 |

### 3.1 家臣四人〔这一段的关系是我补的〕

跟着一个被分封到边陲的王子走，等于把自己的前程换成一个不确定的人。所以四个人各有各的
理由 —— 但**理由可以晚点定**，先定这一条：**他们不是臣子，是压上去了的人。**
这决定了他们的台词里可以有「劝」，但不能有「请示」。

- **塞巴斯蒂安（62，三朝老臣）**：他伺候过你的祖父、你的父亲，也伺候过你。
  别人来边陲是流放，他是**自己要求来的** —— 因为他见过王庭里那些「体面」的结局。
- **阿尔文（24，宫廷学者）**：在宫廷里研究什么都有人比他先做完；边陲这张白纸上，
  他能第一个写下字。
- **薇拉（26，财务官）**：王庭的账是别人替她记的；这里的账是她自己记的。
  毒舌是因为她每天都在算「还能撑几天」。
- **露娜（28，寡妇，人口官）**：她见过一个家怎么散掉，所以对「人愿不愿意留下」这件事
  比谁都敏感。她是这七个人里唯一会问「你昨晚睡了几个时辰」的。

### 3.2 雷纳德：国王的眼睛

- 他不是家臣。他带来**陛下的旨意**，也带来**陛下的赏钱**〔拟：任务每完成一件给 500 金、
  每章全绿再 1000 金的钱，从王庭出〕—— 所以他既是考官，也是金主。
- 他的态度不该跟着你的成绩线性变化：**你越缺人，他越不催**；你越有钱，他越要问钱去哪了。
- 他和塞巴斯蒂安是这七个人里唯一**会当着你的面互相不顺眼**的一对〔拟〕：
  一个替你过日子，一个替国王记账。

### 3.3 伊莎贝拉：偷偷来的那个人

- 大臣之女，18 岁，暗恋主角。〔你定的〕
- 她**偷偷来** —— 不是奉父命，不是受王后所托。所以她的出现本身就该是一件「不该发生的事」。
- 她带来**支线**：不挡章节奖励、可做可不做的那种事〔这条是现有任务系统的口径〕。
- 她该是全局里唯一一个**不谈正事**的人。她一开口就是「你这儿连盏像样的灯都没有」，
  然后顺手留下一件能让你少操半点心的事。
- ⚠️ 她的支线面板**还没设计**。

### 3.4 瑟拉菲娜：不站在任何人那边

- 22 岁，预言家。**她不是家臣**，也不在王庭的名单上。
- 她只在你想问的时候开口（顶栏那个问号），**5 天一次**，问的时候整块封地会静下来。
- 她说话不算账、不点名册、不说「点哪里」—— 她说「我看见了」。
- ⚠️ 她为什么在这块封地上，设定里没写。三种读法〔拟〕：
  （a）封地本来就归她管的方向 —— 她比你先到；
  （b）被王庭送来「陪着」你的，名义上是祥瑞；
  （c）她自己挑的，理由她不说。
  这三条以后要用哪条，会影响她的付费面板怎么卖。

## 四、三条线怎么咬在一起

```
        国王的考核（雷纳德）
               │
   12 人 ──────┼────── 1000 人      ← 主线的唯一尺度：人口
               │
   家臣四人（塞巴 / 阿尔文 / 薇拉 / 露娜）
               │
        她把日子撑住（伊莎贝拉 · 支线，可做可不做）
               │
        神谕（瑟拉菲娜 · 5 天一次，看前面）
```

1. **考核线**：六个章节 = 六道题（先吃饱 → 把人养住 → 科技与材料 → 加工与舒适 →
   分层与市场 → 千人之村）。每题做完，雷纳德把钱放下、把话带走。
2. **来访线**：伊莎贝拉不改考核，只改你。她带来的支线**永远不该是唯一的路**。
3. **神谕线**：瑟拉菲娜不给答案，给**方向**。她该在玩家最想「问一句」的时候显得值钱 ——
   也就是钱快没了、人快走了、或者刚作完一个决定的时候。

**三条线的共同底线**：谁都不许跳出世界说话。没有人说「系统」「面板」「数值」「解锁进度」。

## 七、待定（**别照着猜**）

1. **考核多久**？三年、五年，还是「陛下没有说期限」？（默认读法：没有期限 —— 他自己心里有数。）
2. **考核通过之后**？召回王庭 / 就此封你为这块地的领主 / 换一个人来替你。
3. **国王叫什么**？现在全局只有「陛下」两个字，这是干净的做法，建议就这么留着。
4. **伊莎贝拉怎么来的**？偷跑出来 / 跟着使团 / 父亲默许。她的出现频率和支线内容也全没定。
5. **露娜的丈夫**死了多久、怎么死的 —— 会影响她的每一句话，但也可能永远不需要说。
6. **瑟拉菲娜的来历**（§3.4 的三选一）。
7. **雷纳德的结局**：他会一直站在国王那边，还是有一个「他其实在保你」的转折？
8. **王子的名字**：现在没有。要不要有？（有名字好写剧情，没名字好代入。）
