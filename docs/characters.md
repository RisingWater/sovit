## 二、共同约定

写台词、写任务描述、写提示词都要守的硬约定（违反就会出现「现代人混进中世纪」的破功感）：

1. **称呼玩家一律「殿下」**（伊莲娜例外，叫他「七弟」）。自称各有各的说法
   （塞巴斯蒂安「老臣」、雷纳德「臣」（提国王时）/「我」（私下时）、其余「属下」或直说）。
2. **不出现现代词**：不要「面板」「页签」「界面」「点击」「解锁进度」「数据」「数值」。
   要说「账本」「名册」「文书」「图样」「陛下的旨意」「你把它打开」。
3. **不解释系统**：谁也不说「这个功能」，只说「这一行该修桥」「这里的税该收」。
4. **每个人只看自己那一摊**：薇拉不谈麦子、露娜不谈账本、阿尔文不谈人口、加雷斯不谈收成、
   米拉不谈粮食 —— 她谈的是"对方要什么"。唯一什么都问的是父王的人（前两年是雷纳德跑腿传话）。
5. **好感度不能靠刷**：见 §七 —— **而且本版先不做**（2026-10-18 定）。

### 4.3 长女 · 伊莲娜（25）

| 项 | 设定 |
|---|---|
| 领地 | **曙光城**（东部瓦河下游的学术之城）|
| 性格 | 聪慧、冷静、有政治手腕，但**不争位** |
| 特点 | 赞助学者，掌握王国最好的学院和图书馆 |
| 优势 | 知识、人脉、情报网 |
| 弱点 | 女性身份不被老臣认可 |
| 与你的关系 | 中立偏善意 → **后期盟友** |
| 视觉 | 灰金发半编发髻，深蓝宝石 + 银紫学者袍，银框眼镜推在头顶，手持卷轴与皮面书册、腰挂小型星盘，**无甲无冠** —— 以学者装束体现权力 |

**她为什么不争位**：她看得很清楚 —— 父王"不信血统只信能力"，而她作为一个女性，
无论能力多强，在这个规则里都不可能被立为储君。既然规则本身排除她，
她就不去争一个不可能的位置，而是去经营**规则之外的力量**：知识、舆论、情报网络。

**这让她成为最可怕也最安全的角色**：因为没人把她当威胁，所以诸子都愿意在她面前放松警惕，
说真话。而她听到的每一句话，都可能是将来决定王位归属的关键。

- **前期**：不主动介入，保持中立偏善意的学者姿态。
- **中期**：随着你的领地成形，她主动靠拢 —— 这样的资源只会流向"最有可能赢到最后"的一方。
- **作用**：情报（预警）、知识解锁（银塔学院 → 研究面板的高阶科技）、合法性背书（文明维度）。
- **她的困境（玩家的攻略空间）**：她的能力越被认可，越会被当作"联姻筹码"或"不予立储的理由"。
  玩家可以成为**那个唯一因为她的能力而不是身份认可她的人**。
  〔设定集原话：这条线**不需要恋爱元素也能成立**。〕
- 她称你「七弟」，你称她「姐姐」（或直接叫名字，看她跟你的关系）。

### 6.4 抠图口径（要重跑时照这个来）

`scripts/import-portraits.py` 已经把踩过的坑都写成常量了：

- 键控：`key = G - max(R, B)`；绿底 = 255，主体 ≤ 0。`key < 140` 判为主体。
  **140..215 那一段必须丢掉**（那是绿底上的暗边/投影，放宽了人物轮廓外会多一圈绿影）。
- 过渡带按物理式估 alpha：`a = (255 - key) / (255 - keyF)`（`keyF ≈ -40`）；
  剪影内缩 3px 的"芯"强制 `a = 1`，否则深色衣服会整体变半透。
- 过渡带的颜色从底上反解：`F = (C - (1-a)·B) / a`（**未预乘**）。
- 剩下的绿再按 `G → max(R, B)` 压掉。**不要填洞**（头发之间那几道是真实的缝）。
- 裁切框：1024×1536 源图取 `x 110..910, y 140..1340` → 缩到 **640×960**（2:3）。

> ⚠️ **艾瑟琳是唯一例外，而且抠图由你们自己做**（2026-11 定）：
> 她的裙子是深翡翠绿，和绿幕同色域，上面这套通用脚本会把裙子吃掉。
> **不要用 `import-portraits.py` 过她** —— 手工抠好后把成品 PNG 直接放到
> `godot/assets/portraits/aeslin.png`（640×960、2:3、透明底）即可，后续流程照 §6.5 第 4 步起。

### 6.5 导入流程

1. 把绿幕源图按 §6.3 命名，放进 **`shots/portrait_src/`**（`shots/` 在 `.gitignore` 里，不入库）
2. `python scripts/import-portraits.py` → 写 `godot/assets/portraits/<id>.png`
3. `python scripts/import-portraits.py --probe` → 只出样张到 `shots/portrait_out/`（含并排对照与脸庞表），
   **不覆盖成品** —— 先看样张再导
4. 脚本是**扫目录**的（`glob *.png`），所以加人不改代码，丢文件进去就行

⚠️ 改完 PNG 要跑一次 `godot --headless --path godot --import`，否则 `.ctex` 缓存是旧的
（上次仓库缩略图显示错就是这么来的）。
